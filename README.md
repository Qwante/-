# РейсДоход

**Калькулятор сдельного заработка водителя с планом и фактом, историей смен и месячной статистикой.**

РейсДоход помогает увидеть план на смену, сравнить его с выполненной работой и рассчитать заработок. Приложение работает на Android без регистрации и подключения к интернету.

## Возможности

- Расчёт плана, сдельной расценки и заработка за смену.
- Сравнение плана с фактическим количеством ездок и отображение перевыполнения.
- Выбор даты, автомобиля, расстояния, группы дорог и продолжительности смены.
- Необязательное название объекта или маршрута.
- Сохранение, редактирование и удаление смен с подтверждением.
- Компактные карточки истории, которые раскрываются по нажатию.
- Фильтры по автомобилю и объекту или маршруту.
- Диаграмма заработка по дням и итоги за месяц.
- Выбор месяца и года, быстрый возврат к текущему месяцу.

В диаграмме красный цвет означает невыполнение плана, оранжевый — выполнение ровно по плану, зелёный — перевыполнение. Серый используется, когда в сохранённой смене нет корректных данных о плане.

## Установка

1. Откройте раздел **Releases** этого репозитория.
2. В релизе **РейсДоход 1.2.1** скачайте файл **ReisDohod-1.2.1-universal.apk** из списка **Assets**.
3. Откройте APK на телефоне и при необходимости разрешите установку из выбранного браузера или файлового менеджера.

Нужен **Android 8.0 или новее**. APK содержит варианты для ARM64, ARMv7, x86 и x86_64. Совместимость также зависит от ограничений конкретного устройства и его прошивки.

Файлы **Source code (zip)** и **Source code (tar.gz)** в GitHub не устанавливаются на телефон — для установки нужен APK.

## Обновление и данные

Устанавливайте обновление поверх предыдущей версии, без удаления приложения. При совпадении пакета и ключа подписи локальная история сохраняется.

Удаление приложения или очистка его данных удаляет локальную историю. Если телефон требует сначала удалить старую версию, проверьте совместимость подписи перед продолжением: тестовые сборки из Android Studio могут иметь другую подпись.

## Конфиденциальность

Смены и результаты хранятся локально на устройстве. Аккаунт не требуется. В приложении нет рекламы, аналитических SDK и встроенных покупок; сервер разработчика не используется. Системное резервное копирование Android зависит от настроек телефона.

## О расчётах

Приложение использует встроенные нормативы. Условия оплаты у конкретного работодателя могут отличаться; результат помогает вести собственный учёт смен.
